# Yapnix v0.3.0 — timed reveals and reaction videos

Android 8.0 or newer. Install the signed APK over the existing app without uninstalling to retain local progress and recordings.

- Browse categories, choose a game, and download its content locally.
- Every picture is decoded before Play. Reopening a downloaded game reuses local content.
- Look at each picture, answer aloud, and see/hear the answer after five seconds. No speech validation or correct/missed scoring.
- Optional reaction recording combines only the game composition, front camera and microphone audio. No device-screen capture permission is used.
- Drag or pinch the camera overlay, or use the size slider. Game layout stays independent. Editing is live; saved videos are flattened.
- Recordings remain on the device until explicitly exported or shared.
- On launch/resume, GitHub update checks prompt outside gameplay when a newer release has a matching APK. Profile also has Check for updates. Installation opens the GitHub download in a browser and requires Android installer confirmation.

**Existing v0.1.0/v0.2.0 installs have no update checker. Download and install v0.3.0 manually once to enable future prompts.** A GitHub release cannot add a prompt to an older installed binary.

## Validation

Checks passed: 18 Android release unit tests, 37 backend unit tests, 28 API integration tests, 21 admin tests, and SQL bundle consistency. Full database execution was unavailable because no disposable PostgreSQL test database was configured. Camera/microphone output, hardware encoding, gestures, export, and in-place update installation still require physical-device validation. This release is marked as a pre-release for device testing.

For future updater-compatible releases, increase Android versionCode/versionName, tag vMAJOR.MINOR.PATCH, and attach yapnix-vMAJOR.MINOR.PATCH.apk. Keep the same application ID and signing key.
