# Yapnix v0.6.0 — home, game icons and direct updates

- New Android home with Yapnix wordmark, optional login/profile, animated hero, recent game and game-family/sub-game cards.
- Shared searchable Phosphor icon library in Studio and offline Android vectors; custom square artwork remains optional.
- Redesigned game setup, instructions, play/pause, leave confirmation, compact picture/timer/answer layout and aligned portrait reaction recording.
- In-app downloads and Android installation update the existing app. Version code increases from 6 to 7; the package ID and release signing key are unchanged. Automatic checks run on return to the app with a 15-minute interval; manual checks bypass the interval, and discovery bypasses cached responses.

## Install / update

On v0.5.0, open You → Check for updates, then download/install inside Yapnix. Versions v0.4.0 and older contain the old browser updater; install this APK over the existing app once to replace that updater. Do not uninstall: local videos/progress are retained by an in-place update. Android still requires update installation approval. Debug-signed builds cannot be updated by this release-signed APK.

## Database / Studio

Apply `supabase/sql-editor/upgrade_icon_library.sql` after migrations 001–008, or use `upgrade_existing.sql` for an older database. These files include 009–010. The API keeps guest catalogue reads available before the upgrade, but icon saves require it.
