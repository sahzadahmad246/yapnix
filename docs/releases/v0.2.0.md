# Yapnix v0.2.0 — voice rounds and a refreshed Android app

Install the attached APK over v0.1.0 to keep local progress and recordings. Uses the same signing certificate; Android 8.0 and newer.

- Home, Progress, Recordings and Profile bottom navigation, with a refreshed dark teal design.
- Game metadata and pictures load before Play becomes available. Every question waits for its picture and spoken prompt before the timer starts.
- Questions read aloud using the device text-to-speech engine, animated 3–2–1 preparation and a moving countdown ring.
- Quiet ticking, correct/missed sound effects, and a visible and spoken correct answer after timeout. Missing speech engines fall back to visual play.
- Optional screen recording includes the front-camera preview in the corner. Each recording asks for Android screen-capture consent; leaving or pausing the round stops recording.
- Videos are **silent**: the microphone is reserved for recognizing answers. Recordings stay local unless explicitly exported or shared. App sounds still play during the game.

Production API: https://yapnix-api.onrender.com/api

## Phone test checklist

1. Open Animals, wait for all five pictures to download, and tap Play without recording. Check that the prompt finishes before 3–2–1 and listening begin.
2. Say a correct answer; try a wrong answer; let a question expire. Verify the answer appears and is spoken before the next picture.
3. Repeat with screen + camera recording enabled. Grant camera, microphone and Android screen-capture consent. Verify answers are recognized while the camera is visible.
4. Open Recordings and preview the saved video: it should contain the game screen and face overlay, without audio. Test Save, Share and Delete.
5. Background or pause mid-round. Verify recording stops and the answer timer pauses. Resume, then replay with fresh screen-capture consent.

Physical-device camera, microphone, speech, screen-capture and export checks are **pending**. This is a pre-release for device testing; automated tests and compilation do not verify those hardware paths. Do not uninstall the previous version unless you have exported any recordings you want to keep.
