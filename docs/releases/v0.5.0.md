# Yapnix v0.5.0 — portrait reels, HD capture and direct updates

- Shared 9:16 live preview and export. The square question and camera reaction occupy separate areas; the camera can never cover the question.
- Camera settings live in a closable bottom drawer opened from the edit button. Drag/resize stays inside the reaction area; mirror, shape and reset remain available.
- Full HD 1080 × 1920 / 30fps recording is attempted first, with an HD 720 × 1280 / 24fps fallback if the phone cannot initialize the Full HD encoder. H.264/AAC MP4, microphone audio, no device-screen capture. Source game images use up to 1080 pixels with a heap-aware budget.
- Camera frames come from a native CameraX analysis stream rather than screen-sized preview snapshots; export is independent of the small on-screen camera view.
- Refined charcoal/ivory/lime home, game, play, results, progress and profile screens, with consistent vector icon actions and less decoration.
- Google display name/profile photo appear on Home and You when available, with initials fallback. Existing stored login sessions remain compatible.
- Local videos use a three-column portrait Reels grid. Overflow menus offer Play, Save, Share and confirmed Delete. Playback has seeking and pause controls; export keeps the original file quality.
- Updates download inside Yapnix with progress, cancel and retry. Release URL/redirect hosts, file size, available SHA-256, package ID, newer version code and signing certificate are validated before offering installation. Android install permission and final installer approval remain explicit user actions.

## Installation

Install this signed APK over the existing app without uninstalling. The application ID and signing key are unchanged. Older installed versions still use their old update interface; install v0.5.0 once to enable direct downloads for future updates.
