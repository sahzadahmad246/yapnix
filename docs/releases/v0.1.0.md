# Yapnix v0.1.0 — first Android test release

Signed Android APK for Android 8.0 (API 26) and newer.

- Guess category with standalone image/answer games.
- Animals content is fetched from the production API (five published questions at release validation).
- Game-wide question prompts, timed voice answers and local progress.
- Optional Google sign-in and explicit progress synchronization.
- Optional reaction camera recording, stored on the device with explicit export/share.

Production API: https://yapnix-api.onrender.com/api
Admin Studio: https://yapnix.vercel.app

Download the APK attached to this release and open it on an Android device. Android
may ask permission to install from the browser or file manager used for the download.
The APK is directly installable; this release does not include a Play Store AAB.

Validation: release compilation/unit tests, APK signature and production game
availability are checked before upload. Physical-device validation of login,
speech recognition, microphone/camera behavior and video export is still pending.
This is a pre-release for testing, not a claim of production device validation.

SHA-256 checksums are attached alongside the APK. Source code is available through
the release tag. Signing keys, passwords and local environment files are excluded.
