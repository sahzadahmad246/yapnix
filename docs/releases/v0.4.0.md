# Yapnix v0.4.0 — new game UI and reaction studio

## Changes

- New cream/purple game screens, original vector icons, concise game cards and category browsing.
- Square center-cropped pictures stay visible immediately. The dark image cover and extra preparation countdown are removed. The five-second timer starts when the spoken prompt finishes.
- Small original tap, start, tick, answer-reveal and completion sounds.
- Live camera studio before Play: drag, pinch, size slider, mirror, portrait/circle shape and reset. Camera controls and system UI are excluded from recordings.
- Replace unsupported Canvas drawing on a video-encoder surface with an EGL/OpenGL input path. Frame composition remains on main; GPU submission and MP4 finalization run on a worker. Saves validate playable video and microphone tracks before appearing in the library.
- Stop pending recording when leaving setup. Recording notification includes Stop. Pausing finalizes the current clip; resuming continues gameplay without recording another clip.
- Video library has square thumbnails, durations, playback/seek controls and explicit save/share/delete actions.
- Recently decoded games stay cached within a memory limit; large rounds use a heap-aware decode budget. Standard five-picture rounds retain full 720-pixel video resolution.
- Small optimized signed APK; no speech recognition, speech model, device-screen recording or automatic uploading.

## Installation and testing

Install over the existing app without uninstalling; application ID and signing key are unchanged. v0.3.0+ can use Profile → Check for updates. Earlier versions need this APK installed manually once.

This is a **device-testing pre-release**. No physical phone is connected here. Compilation, automated suites, signing and package inspection are checked before publication; actual camera/microphone capture, EGL encoder support, A/V sync, MP4 playback/export and installation must be tested on a phone. The user opted to receive the APK for that test.

Phone test: enable recording, wait for live camera preview, adjust framing, Play, say an answer, complete a round, open Videos, play/seek, Save and Share. Also test leaving setup during startup, pause/background, replay, and playing with recording off or permissions declined. A recording failure now logs its stage under `YapnixRecording` in Android logcat.
