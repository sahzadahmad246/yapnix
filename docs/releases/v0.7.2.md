# Yapnix v0.7.2 — reliable updates and what’s new

- Update checks use a static release feed, avoiding GitHub’s anonymous release-API quota; the release API remains a fallback.
- Your profile shows a persistent Update available card with version, what’s new and an Update now button, even after dismissing the reminder.
- Update dialogs include release highlights. Service errors no longer incorrectly claim you are offline.
- APK downloads stay inside Yapnix and retain checksum, package, signing-certificate and higher-version verification.

## Install / update

If an older build’s checker is rate-limited, download this APK once and install it over the existing Yapnix app. Keep the app installed to retain videos and progress. From 0.7.2 onward, checks use the new static feed. Android still requires installation approval.

No database migration is required. The profile card appears when a newer release exists, rather than advertising the version already installed.
