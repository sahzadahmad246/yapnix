# Yapnix v0.7.1 — cleaner home and game discovery

- Flat, full-width bottom navigation with clear Home, Progress, Videos and You tabs and a restrained active indicator.
- The animated home hero background extends across the top and side edges, with a straight bottom edge. Compact recent-game and category cards replace the oversized artwork tiles.
- Guess is a category; Animals and other playable entries are games. Android no longer labels them “sub-games”.
- Category pages keep the centred title, back button, question-mark help button and description. The repeated large icon and extra How to play button are removed.
- Game cards show a name, icon and short round facts. Tapping one opens a scrollable details sheet with the full description and a Get ready button.
- Camera/microphone hardware is explicitly optional for guest play. Android 8.0 keeps a readable system navigation bar, with dark navigation icons enabled only on supported Android versions.
- Version 0.7.1 / code 8 skips 0.7.0 and updates the existing release-signed app in place.

## Install / update

Open You → Check for updates → Update now, then install the downloaded update inside Yapnix. Keep the existing app installed to retain local videos and progress. Android requires installation approval.

## Database

No new migration is required for this Android UI update.
