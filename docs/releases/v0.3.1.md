# Yapnix v0.3.1 — smaller Android release

- Remove the unused offline speech model, Vosk/JNA native libraries, speech-model build download and obsolete shared-microphone/muxing code.
- Remove the unused CameraX video dependency.
- Enable R8 code optimization and resource shrinking for signed release builds.
- Preserve five-second answer reveals, local game downloads, camera overlay editing, microphone reaction recording and GitHub update prompts.

Install over v0.3.0 without uninstalling. The application ID and release signing key are unchanged. v0.3.0 can detect this release through its GitHub update checker; Profile → Check for updates can check immediately. v0.1.0/v0.2.0 require one manual APK installation because those versions have no updater.

Verification: signed release build, 16 Android release unit tests and release lint passed. APK reduced from 86.38 MiB to 1.99 MiB (97.7% smaller). APK inspection confirms no speech model or Vosk/JNA native libraries remain.

This is a testing pre-release. Physical-device camera/audio/export and installation validation remains pending.
